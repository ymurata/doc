# 全プロジェクト共通の指示

## 言語
- 応答、説明、コミットメッセージ、PR の説明は日本語で書く
- コード中の識別子と、既存プロジェクトが英語のコメントや文書を使っている場合は、その言語に合わせる

## 作業の進め方
- 変更前に周辺のコードを読み、既存の命名・コメント量・書き方に合わせる
- 依頼されていない機能追加やリファクタリングはしない
- 複数の選択肢があり、どれを選ぶかで結果が変わる場合は、実装前にユーザーへ確認する
- 完了を報告する前に、テストやビルドなど検証できるものは実行する。失敗したら出力を添えてそのまま報告する

## Git
- コミットや push は依頼されたときだけ行う。デフォルトブランチへ直接コミットしない
- `git push --force`、`git reset --hard` など履歴や作業内容を失う操作は、確認なしに実行しない

## セキュリティ
- `.env`、秘密鍵、認証情報は読まない・出力しない・コミットしない
- 外部サービスへ送信する内容は、送る前にユーザーへ確認する

## memory
- 記録するのは、コードや git 履歴から分からないこと(ユーザーの好み、訂正された方針、進行中の背景、外部リソースの場所)だけにする
- コード構成や過去の修正内容など、リポジトリを見れば分かることは記録しない
- 1 ファイル 1 事実にし、重複する記録は新規作成せず既存を更新する。誤りと分かった記録は削除する
- `MEMORY.md` は 1 行 1 件の索引にとどめ、内容は書かない
